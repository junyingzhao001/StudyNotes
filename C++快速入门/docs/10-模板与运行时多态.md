# 10 · 模板与运行时多态

## 本篇目标

看懂 template、类型参数、继承、virtual 和 override。

## 学习作用

理解 vector<int> 这样的泛型类型，以及接口指针调用具体实现的代码。

## 核心知识

### A. 模板：编译期类型适配

模板按类型生成代码：`template<typename T>` 中 T 是类型参数。函数模板使用到的操作必须被实际类型支持，例如本例需要支持 `>`。模板定义通常放在头文件中，让实例化它的编译单元能看到定义。

Java 泛型常通过类型擦除实现，基础类型通常需要 Integer 等装箱；C++ 模板会针对使用到的具体类型实例化，`vector<int>` 可直接存 int。模板错误可能很长，先找第一条落在自己代码的诊断并核对实际类型。

### B. virtual：运行时分派

虚函数用于运行时多态：通过基类引用或指针调用 virtual 方法，会选择实际对象的实现。`override` 让编译器检查确实覆盖了基类虚函数，避免拼错签名。

纯虚函数 `= 0` 使类成为抽象类，不能直接创建该类对象。通过基类指针销毁派生对象时，基类应有虚析构函数。`virtual ~Shape() = default;` 使用编译器生成的析构实现。

不要把派生对象按值复制进普通基类对象，否则可能发生对象切片，丢失派生部分。多态接口通常使用引用或智能指针；并不是所有类都需要继承，数据和行为组合往往更简单。

Java 普通实例方法默认进行动态分派，`@Override` 帮助检查覆盖；C++ 必须在基类接口显式写 virtual，派生类用 override 检查。C++ 的纯虚基类在用途上接近 Java interface/abstract class，但它仍是 C++ 类，尤其要考虑析构和按值切片。

demo 中 `make_unique<Rectangle>` 得到 unique_ptr<Rectangle>，随后移动转换为 unique_ptr<Shape>。对象本身仍是 Rectangle；Shape 指针调用 virtual area 时，运行期进入 Rectangle::area。

## 可运行 demo

源码：[demos/10.cpp](../demos/10.cpp)。从 `C++快速入门` 目录执行：

```bash
mkdir -p build
c++ -std=c++17 -Wall -Wextra -Wpedantic -g demos/10.cpp -o build/demo_10
./build/demo_10
```

```cpp
#include <iostream>
#include <memory>

template<typename T>
T larger(T left, T right) { return left > right ? left : right; }

class Shape {
public:
    virtual ~Shape() = default;
    virtual double area() const = 0;
};

class Rectangle : public Shape {
public:
    Rectangle(double width, double height) : width_(width), height_(height) {}
    double area() const override { return width_ * height_; }
private:
    double width_;
    double height_;
};

int main() {
    std::cout << "larger: " << larger(3, 7) << '\n';
    std::unique_ptr<Shape> shape = std::make_unique<Rectangle>(3.0, 4.0);
    std::cout << "area: " << shape->area() << '\n';
}
```

预期输出：

```text
larger: 7
area: 12
```

## 两条执行路径分开看

```text
larger(3, 7)
  └─ 编译期确定 T = int，生成/选择 int 版本 → 返回 7

shape->area()
  └─ shape 的静态接口是 Shape
     └─ 运行时对象是 Rectangle → 调用 Rectangle::area → 返回 12
```

模板解决“同一套代码适配不同类型”，虚函数解决“通过统一接口调用不同对象行为”。二者都叫多态，但发生时机不同。

## 常见坑

`larger(3, 4.5)` 不能由这里的同一个 T 自动推导成功；可以传同类型参数或显式使用 larger<double>(3, 4.5)。
