# 02 · 类型初始化与常用语法

[返回学习地图](../README.md) · [下一篇：函数引用与const](03-函数引用与const.md)

## 本篇目标

理解值、初始化、const、auto、范围 for 和 enum class。

## 学习作用

读懂现代 C++ 的日常语法，减少未初始化、隐式转换和整数除法造成的错误。

## 核心知识

局部基础类型应当初始化：写 `int count{0};`，不要写一个未赋值就读取的 `int count;`。花括号初始化能阻止许多窄化转换，例如 `int x{3.5};` 编译失败。

`auto` 是编译期类型推导，不是动态类型。`auto n = 3;` 的 n 是 int；`const` 限制通过该变量进行修改。字符串通常选 `std::string`，可变长度序列通常选 `std::vector`。

`scores.size()` 的类型通常是 `std::size_t`，它是用于表示对象大小和索引的无符号整数类型。入门时用 `auto size = scores.size()` 最省心；把 size_t 和可能为负的 int 比较前要先确认数据范围和转换规则。

`for (int score : scores)` 每次取得一个元素的副本；第 03 篇会说明如何用引用修改原元素。`enum class` 创建带作用域的枚举，需要写 `Level::Beginner`，减少命名冲突。

两个整数相除仍执行整数除法：`5 / 2` 得到 2。先把一个操作数转换为浮点数，才会得到小数。`static_cast<double>(sum)` 是明确表达转换意图的写法。

## Java 对照

| Java | C++17 | 差别 |
| --- | --- | --- |
| `var n = 3` | `auto n = 3` | 都是编译期推导，变量并未变成动态类型 |
| `final int n` | `const int n` | 对基础值都限制重新赋值 |
| `final List<T>` | `const std::vector<T>` | Java final 只固定引用，仍可改 List 内容；C++ const vector 不能调用普通修改方法 |
| `List<Integer>` | `std::vector<int>` | vector<int> 直接存 int，无 Integer 装箱 |
| 强制类型转换 | `static_cast<T>(value)` | C++ 推荐明确写出转换意图 |

## 可运行 demo

源码：[demos/02.cpp](../demos/02.cpp)。从 `C++快速入门` 目录执行：

```bash
mkdir -p build
c++ -std=c++17 -Wall -Wextra -Wpedantic -g demos/02.cpp -o build/demo_02
./build/demo_02
```

```cpp
#include <iostream>
#include <string>
#include <vector>

enum class Level { Beginner, Advanced };

int main() {
    const std::string language{"C++"};
    std::vector<int> scores{80, 90, 100};
    auto sum = 0;
    for (int score : scores) {
        sum += score;
    }
    const double average = static_cast<double>(sum) / scores.size();
    const auto level = Level::Beginner;
    if (level == Level::Beginner && average >= 60) {
        std::cout << language << " average: " << average << '\n';
    }
}
```

预期输出：

```text
C++ average: 90
```

## 跟踪 demo

scores 依次提供 80、90、100，范围 for 每次把一个 int 复制给 score；sum 从 0 变为 80、170、270。转换为 double 后再除以 3，average 得到 90。level 等于 Beginner 且 average 达标，所以执行输出。

## 常见坑

`vector<int>{3, 7}` 是两个元素 3 和 7；`vector<int>(3, 7)` 是三个值为 7 的元素。不要把两种初始化机械替换。
