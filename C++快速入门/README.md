# C++ 快速入门：从 Java/Kotlin 基础到能读项目、改功能

适合已经写过 Java、Kotlin、Python、JavaScript 等语言，想系统上手 C++ 的学习者。默认你理解变量、条件、循环、函数和基本面向对象；Java/Kotlin 对照是主线，其他语言背景也能阅读。

本课程使用 **C++17**，分成三段：第一段建立值语义、生命周期、所有权和标准库基础；第二段完成带持久化、测试和构建配置的任务清单项目；第三段学习线程同步，并完成一个带 future 的后台任务执行器。目标是让你能进入小型真实项目，在指导下构建代码、定位入口、修改普通功能、补测试和排查常见错误。

它不是完整语言规范，也不承诺学完就能独立负责生产级 C++ 系统。高级并发、网络、GUI、JNI/NDK、性能和 ABI 等内容仍需按实际方向继续学。

## 第一轮 7 天安排

1. 第一天：00–02，先切换对象模型，再跑通程序和常用语法。
2. 第二天：03–04，用纸画出变量、别名和地址，重点理解生命周期。
3. 第三天：05–06，追踪对象创建、移动、销毁，建立所有权意识。
4. 第四天：07–08，练习容器、查找、过滤和排序。
5. 第五天：09–10，理解拷贝/移动，再看模板和多态。
6. 第六天：11，主动触发失败，观察退出码和错误信息。
7. 第七天：12，运行带持久化的项目，理解接口、实现和输入输出。

第二轮学习 14–16：先理解 C/NDK 常见数据边界，再用 CMake 和测试组织项目，最后完成调试 lab 与 `pending` 功能。

第三轮学习 17–22：先掌握 thread/join 和共享数据规则，再学习 mutex、condition_variable、future 与 atomic，最后画通 TaskExecutor 的调用路径并重写一个由 main 负责关闭的简化版。第二遍再理解完整实现的模板适配和自关闭防护。每篇先预测输出，再运行；随后完成修改题；最后关掉示例自己重写关键逻辑。遇到问题先读 [语法与读码速查](docs/13-语法与读码速查.md)。

## 从其他语言切换时最重要的变化

| 已有习惯 | 在 C++ 中需要重新确认 |
| --- | --- |
| `User b = a` 通常共享同一对象 | `User b = a` 通常复制出独立对象 |
| 对象参数复制的是引用值 | `T` 复制对象，`T&` 才明确表示别名 |
| 局部对象由 GC 决定何时回收 | 局部对象离开作用域时确定析构 |
| try-with-resources 管理资源 | RAII 让资源随对象析构自动释放 |
| null 对象引用 | 根据意图选择指针、optional 或空智能指针 |
| ArrayList / HashMap / TreeMap | vector / unordered_map / map，元素默认按值存储 |
| Java 泛型 | C++ 模板通常在编译期实例化，可直接使用 `vector<int>` |
| package/import/classpath | namespace/include/link 是三件不同的事 |
| `Thread` 用完可交给运行时回收 | joinable 的 `std::thread` 析构会终止程序，必须先 join/detach |
| `synchronized` / `AtomicInteger` | mutex + RAII 锁 / `std::atomic<int>`，C++ `volatile` 不负责线程同步 |
| `ExecutorService` | C++17 标准库没有直接对应；本课程实现最小 TaskExecutor 来理解其内部协议 |

## 怎样算真正完成

- 能解释 `T`、`T&`、`const T&`、`T*`、`unique_ptr<T>` 各自在表达什么。
- 能给任务项目新增命令，同时修改接口、实现和测试。
- 能用数据文件运行两次程序，并看到上次任务仍在。
- 能从编译或链接报错定位到漏掉的声明、实现或 target。
- 能用断点找到 debug_lab 的条件错误，用 Sanitizer 找到越界行。
- 能清楚说出某个借用对象何时失效，而不是只看程序有没有崩。
- 能说明数据竞争为何是未定义行为，并用 mutex 或 atomic 选择正确的同步方式。
- 能为后台 worker 定义“停止接收、排空队列、通知、join”的关闭协议，并从 future 取得结果或异常。

完成这些即可开始参与小型实际项目，也能读懂和修改常见 worker、任务队列与一次性异步计算代码。生产级线程池、取消、超时、性能调优和无锁结构仍需要结合实际框架继续学习。之后如果目标是 Android JNI/NDK，继续学习 JNI 引用规则、线程附加、Gradle/CMake native 配置和 ABI；其他方向按第 16 篇的路线继续。
