# C++ 系统学习：从能读代码到能做项目

这套资料适合已经写过 Java、Kotlin、Python 或 JavaScript，但刚开始系统学习 C++ 的开发者。课程主体使用 C++20，同时在容易遇到存量项目的地方说明 C++17 写法。

你不需要先背完语法。每篇文章先说明它解决什么实际问题，再解释需要的规则和 API，然后用一个案例验证。遇到暂时用不到的章节，可以根据“学习级别”跳过，等项目需要时再回来。

## 每篇文章的阅读顺序

1. **先说这篇讲什么**：用几句话给出结论。
2. **它有什么用**：说明这个知识会出现在项目的哪里。
3. **要解决的问题**：先理解痛点，再看语法。
4. **核心概念**：术语第一次出现时立即用普通话解释。
5. **案例**：围绕一个场景讲透，不连续堆多个例子。
6. **API 和作用**：写清参数、返回值、所有权和失败方式。
7. **验证**：给出能运行或能检查的结果。
8. **常见坑**：说明失效条件、限制和容易误解的地方。
9. **马上动手**：读完立刻做一件小事。
10. **学完标准**：知道什么时候可以进入下一篇。

## 学习路线

### 第一阶段：运行与对象模型

00–07。学会构建程序，理解类型、函数、作用域、头文件、宏、指针、引用和生命周期。

### 第二阶段：类与所有权

08–14。学习类、构造析构、RAII、拷贝移动、智能指针、继承、多态和模板。

### 第三阶段：标准库与错误处理

15–19。学习字符串、容器、算法、迭代器、ranges 和错误模型。

### 第四阶段：文件与系统边界

20–24。学习流、文本和二进制文件、filesystem、JSON/配置以及 C API。

### 第五阶段：工程开发

25–28。学习 CMake、测试、调试、Sanitizer、依赖、日志和配置组织。

### 第六阶段：并发

29–34。学习 thread、jthread、锁、条件变量、future、atomic 和任务执行器。

### 第七阶段：网络

35–40。学习 TCP/UDP、Asio、消息边界、超时、取消、HTTP、TLS 和网络测试。

### 第八阶段：性能、安全与综合项目

41–43。学习测量性能、限制不可信输入，并完成一个带网络同步的任务服务。

### 第九阶段：通用补充与方向专题

44–49 建议所有人完成；50–55 根据并发、网络、系统、后端或大型项目方向选学。

## 建议节奏

- 第一轮先学 00–28，目标是能读懂并修改普通多文件项目。
- 第二轮学 29–43，目标是能处理线程、异步 I/O 和基础网络服务。
- 第三轮补 44–49，再按工作方向选择 50–55。
- 每学完一篇，先做“马上动手”，不要只读文字。

## 编译示例

没有特殊说明时，从课程目录执行：

```bash
c++ -std=c++20 -Wall -Wextra -Wpedantic -g examples/文件名.cpp -o build/程序名
./build/程序名
```

线程示例还需要 `-pthread`。网络、JSON、测试框架等第三方库会在对应章节说明安装和替代方案；在理解概念前，不要求先解决依赖安装。

课程提供了一组可直接运行的关键示例，见 [examples 说明](examples/README.md)。执行 `bash scripts/run_examples.sh` 可以统一编译并核对输出。

## 能力边界

完成主线后，可以在代码评审和测试保护下参与中小型 C++ 项目。它不等于已经掌握编译器实现、无锁算法、内核网络栈、密码学或大型分布式系统。这些方向需要结合真实项目继续深入。
