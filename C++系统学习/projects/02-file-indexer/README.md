# 项目二：并发文件索引器

## 这个项目练什么

把 filesystem、任务队列、线程池、future、取消、锁和结果合并连起来。

## 必须实现的行为

- 输入一个目录，只统计普通文件。
- 输出文件数、总字节数和扩展名分组。
- 工作线程数量可以配置，但至少为 1。
- 收到停止请求后不再提交新文件，并安全等待已开始工作结束。
- 单个文件读取失败要记录原因，不让整个进程崩溃。

## 关键设计

目录遍历只负责发现路径；线程池负责处理文件；结果汇总对象由一把 mutex 保护。不要让多个线程同时修改同一个普通 map 而不加锁。

## 必测场景

- 空目录、嵌套目录和无权限文件。
- 文件在扫描期间被删除。
- worker 任务抛异常。
- 立即停止与处理一半后停止。
- 线程数为 1 和大于 1 的结果一致。

## 完成标准

普通构建、ASan/UBSan 和 TSan 路径都通过；测试不用固定 sleep 猜线程时序；关闭后没有 joinable 线程。
