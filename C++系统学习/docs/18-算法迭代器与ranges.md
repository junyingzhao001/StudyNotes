## 先说这篇讲什么

这篇用一个“过滤、排序、查找”流程讲标准算法。读代码时先看算法名，再看 Lambda 条件。

## 它有什么用

标准算法能直接表达意图，减少手写循环的下标和边界错误。迭代器则把算法与具体容器连接起来。

## 要解决的问题

remove_if 并不会真正缩短 vector，它只把保留元素移到前面并返回新的逻辑末尾，还需要 erase。

## 先把几个词说清楚

- **迭代器**：表示容器中一个位置的对象
- **谓词**：返回 true/false 的判断函数
- **范围**：一段可遍历的元素序列

## 一个案例

删除低于 60 的成绩，按降序排列，再找到第一个至少 90 的成绩。一个场景串起三个算法。

```cpp
scores.erase(std::remove_if(scores.begin(), scores.end(),
    [](int x) { return x < 60; }), scores.end());
std::ranges::sort(scores, std::greater{});
```

## 常用 API 和作用

| API / 规则 | 用来做什么 |
| --- | --- |
| `sort` | 排序一个范围 |
| `find_if` | 找到第一个满足条件的元素 |
| `remove_if + erase` | 删除满足条件的 vector 元素 |
| `ranges::views` | 延迟组合过滤和转换视图 |

## 怎么验证自己真的理解了

输入 `{50, 90, 70}`，结果应为 `{90, 70}`。把 erase 去掉，观察 size 为什么没变。

## 常见坑

- 容器修改后，旧迭代器可能失效。
- 排序要求比较关系一致，不能写会自相矛盾的比较器。
- view 常是借用，源范围销毁后不能继续使用。

## 马上动手

用 find_if 找到第一个偶数，再用 transform 生成每个数的平方。
