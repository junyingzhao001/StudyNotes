## 先说这篇讲什么

这篇用订单状态说明 if、switch、循环、struct 和 enum class。目标是让代码表达业务状态，而不是散落魔法数字。

## 它有什么用

项目代码大多是在读取状态、做判断、更新数据。状态表达清楚，非法分支更容易被发现，日志和测试也更好写。

## 要解决的问题

如果用 0、1、2 表示订单状态，调用者必须猜数字含义，还可能传入 99。枚举把可选状态限定在一组有名字的值中。

## 先把几个词说清楚

- **struct**：把相关数据放在同一个对象中
- **enum class**：有作用域的有限选项集合
- **分支**：根据条件选择一条执行路径

## 一个案例

订单只能从待支付进入已支付或已取消。用 enum class 后，函数参数直接说明它接收的是订单状态。

```cpp
enum class OrderState { pending, paid, cancelled };

struct Order {
    int id;
    OrderState state;
};
```

## 常用 API 和作用

| API / 规则 | 用来做什么 |
| --- | --- |
| `if / else` | 处理布尔条件 |
| `switch` | 按有限枚举值选择分支 |
| `for (const auto& x : xs)` | 逐个只读访问容器元素 |
| `break / continue` | 结束循环或跳过本轮 |

## 怎么验证自己真的理解了

为三个状态分别写 switch 分支并打印文字。打开警告后故意漏掉一个枚举分支，观察编译器是否提醒。

## 常见坑

- switch 中忘记 break 可能继续执行下一个 case；确实需要贯穿时应明确标注。
- struct 的公开字段适合简单数据记录；有复杂约束时应交给 class 维护。

## 马上动手

增加 `shipped` 状态，并规定只有 paid 才能进入 shipped。为非法转换返回 false。

## 学完标准

能用结构体表达一组相关数据，用 enum class 表达有限状态，并写出清楚的状态转换。
