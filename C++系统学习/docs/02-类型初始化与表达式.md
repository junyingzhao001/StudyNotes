## 先说这篇讲什么

这篇讲变量怎样从创建时就拥有正确的类型和值。重点是初始化、const、类型推导和显式转换。

## 它有什么用

许多 C++ 问题来自未初始化、整数除法、符号位转换或隐式窄化。让类型表达意图，可以把错误提前到编译阶段。

## 要解决的问题

如果平均分用整数相除，小数会直接丢失；如果变量先声明后赋值，中间路径可能忘记赋值。

## 先把几个词说清楚

- **初始化**：变量创建时立即得到值
- **const**：通过这个名字不能再修改对象
- **窄化**：把值放进表示范围更小的类型，可能丢信息

## 一个案例

三个整数总分除以人数时，先把总分转成 double，运算才会保留小数。

```cpp
const int total{250};
const int count{3};
const double average =
    static_cast<double>(total) / count;
```

## 常用 API 和作用

| API / 规则 | 用来做什么 |
| --- | --- |
| `{} 初始化` | 能拦住一部分窄化转换 |
| `auto` | 由右侧表达式推导类型 |
| `constexpr` | 允许值在编译期计算 |
| `static_cast<T>` | 明确写出想进行的类型转换 |

## 怎么验证自己真的理解了

打印 average，应得到约 83.3333。去掉 `static_cast<double>` 后再运行，对比结果并解释为什么不是编译器算错。

## 常见坑

- `auto` 省略的是重复类型名，不是让类型消失；仍要知道推导结果。
- 无符号整数与负数混算容易得到意外的大正数。
- 浮点数通常不能直接用 `==` 判断计算结果是否完全相等。

## 马上动手

写一个摄氏温度转华氏温度的小程序，确保除法或乘法不会被整数规则截断。

## 学完标准

能说出每个变量的实际类型，知道何时使用 const、auto 和显式转换。
