# 04 · 函数、重载、引用与 Lambda

[返回学习地图](../README.md) · [上一篇](03-控制流与数据建模.md) · [下一篇](05-作用域头文件与cpp.md)

## 先说这篇讲什么

这篇讲函数参数怎样表达复制、只读借用和可修改借用，也介绍重载与小型回调 Lambda。

## 它有什么用

函数签名就是接口合同。读懂它，你能在调用前判断会不会复制对象、会不会修改调用者的数据，以及借用需要保持多久。

## 要解决的问题

Java 对象参数常让人习惯“变量里放的是引用”。C++ 的 `T value` 通常会复制 T，`T&` 才是同一个对象的别名。

## 先把几个词说清楚

- **传值**：函数得到独立参数对象
- **引用**：已有对象的别名
- **Lambda**：可以就地写出的匿名函数对象

## 一个案例

给任务标题加前缀需要修改原字符串，因此参数用 string&；只打印标题时使用 const string&。

```cpp
void addPrefix(std::string& title) {
    title = "[todo] " + title;
}

void print(const std::string& title) {
    std::cout << title << '\n';
}
```

## 常用 API 和作用

| API / 规则 | 用来做什么 |
| --- | --- |
| `T value` | 复制或移动一个值进入函数 |
| `const T&` | 只读借用，避免复制大对象 |
| `T&` | 修改调用者对象 |
| `std::function` | 保存一种统一签名的可调用对象 |

## 怎么验证自己真的理解了

创建 title，先调用 addPrefix 再调用 print。另写一个传值版本，确认传值版本中的修改不会影响调用者。

## 常见坑

- 不要返回局部变量的引用或指针；函数结束后对象已经销毁。
- Lambda 使用 `[&]` 捕获时要确认它不会活得比被引用对象更久。
- 重载只看参数列表，不能只靠返回类型区分。

## 马上动手

实现 `updateIf(std::string&, predicate)`：只有 predicate 返回 true 时才加前缀。

## 学完标准

看到函数签名就能说出是否复制、是否修改调用者，并能写一个安全的小型 Lambda。
